# Security Statement

This repo is mainly for me, my professor, and TA(unpaid) to use for class work.

The security risk is low, but if someone gets access to it, they could copy my work or change the code. I also make sure not to put passwords, API keys, or other private information in the repo.

To keep it secure, I use GitHub rules to protect the main branch and avoid unwanted changes. More advanced protections are not necessary because I am the main person working on this repo.
